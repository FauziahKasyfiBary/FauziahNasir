# Academic Portfolio — Dr. Fauziah

Website statis responsif dengan HTML, CSS, dan JavaScript untuk GitHub Pages.

## File
- `index.html`: struktur dan konten.
- `style.css`: desain navy responsif.
- `script.js`: navigasi mobile dan tahun otomatis.

## Publikasi
1. Unggah ketiga file ke root repository GitHub.
2. Pastikan nama halaman utama `index.html`.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
5. Buka URL Pages yang ditampilkan GitHub setelah deployment.

## Sebelum dipublikasikan
Periksa nama/gelar, institusi, jabatan akademik, riwayat pendidikan, email, serta tautan profil. Tambahkan foto profil dan publikasi yang telah diverifikasi. Template menggunakan Google Scholar ID yang sebelumnya tersedia dalam percakapan; pastikan profil tersebut memang milik pemilik website.
